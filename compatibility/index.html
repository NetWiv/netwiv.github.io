Compatibility

NetWiv keeps the native libraries and the frontend API of a TAURI® app and replaces its Rust core with .NET. This page shows that relationship, then measures how much of the API the desktop SDK, @netwiv/api, implements.

Looking for operating system support? See where NetWiv runs

Where this is heading

NetWiv was born on top of TAURI. The aim is for @netwiv/api to stand on its own.

  1. Today@netwiv/api→pinned @tauri-apps/api codeThe SDK delegates to pinned upstream frontend code internally. An independent frontend transport is not implemented yet.
  2. Goal@netwiv/api→NetWiv’s own APIThe SDK becomes a NetWiv API in its own right, with its own frontend transport and no TAURI frontend code underneath.
  • Apps already import only @netwiv/api, so the change is meant to happen behind it rather than in app code.

Blazor Hybrid Implemented

Managed Razor UI hosting

Optional NetWiv.BlazorHybrid provides matching .NET 8/9/10 assets for Windows x64, Linux x64 and macOS arm64 and defaults to Microsoft's managed WebView services via AddNetWivBlazorHybrid(). Standard component and JS-invokable discovery do not require the experimental registry. Selected native rendering, command IPC, interop and lifecycle checks passed on physical Windows/macOS and Linux under WSLg on X11 and native Wayland. Rider/Visual Studio UI acceptance, Hot Reload and arbitrary component libraries remain unverified. See Blazor Hybrid for platform and debugger validation.

How to read this

Implemented
An execution path exists in the stated platform scope. It does not imply full argument, error or GUI equivalence.
Declaration available
A type or constant comes from the pinned upstream declarations. Its members are counted on their own.
Left out of the SDK
In the upstream inventory but not in the SDK. Still counted in the upstream reference.
Not implemented
Unavailable, including declarations that return empty results or ignore options.
Intentional difference
Deliberately unsupported, such as runtime identity checks. A documented difference, not a pass.
