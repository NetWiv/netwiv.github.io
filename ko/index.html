코딩 에이전트 연결

netwiv mcp는 프로젝트의 CLI로 읽기 전용 MCP 서버를 띄웁니다. 에이전트는 그 NetWiv 버전의 가이드와 프로젝트의 설정, 권한, 명령을 읽습니다.

에이전트에게 맡기기

이 프롬프트를 코딩 에이전트에 붙여 넣으세요. 빠진 것을 설치하고, 서버를 연결하고, Claude Code나 Codex라면 NetWiv 스킬 설치를 제안한 뒤 연결을 확인합니다.

직접 설정하기

사용하는 코딩 에이전트를 고르세요.

  1. NetWiv 마켓플레이스 추가

    /plugin marketplace add NetWiv/skills

  2. 스킬 설치

    /plugin install netwiv@netwiv

  3. 플러그인 다시 불러오기

    /reload-plugins

스킬은 NetWiv 버전과 관계없이 쓸 수 있고, 버전별 가이드는 프로젝트의 CLI가 제공합니다. netwiv new로 만든 프로젝트에는 .mcp.json이 이미 들어 있으니, dotnet tool restore를 한 번 실행하고 Claude Code가 처음 netwiv 서버를 불러올 때 승인하세요.

  1. NetWiv 마켓플레이스 추가

    codex plugin marketplace add NetWiv/skills

  2. 스킬 설치

    codex plugin add netwiv@netwiv

  3. 프로젝트 CLI 복원

    dotnet tool restore

  4. ~/.codex/config.toml에 서버 등록

    [mcp_servers.netwiv]
command = "dotnet"
args = ["tool", "run", "netwiv", "--", "mcp"]

Codex는 스킬을 모든 프로젝트에 설치합니다. dotnet tool run이 프로젝트의 CLI를 찾도록 프로젝트 폴더에서 Codex를 시작하세요. 다시 시작하면 스킬과 서버가 함께 불려 옵니다.

  1. 프로젝트 CLI 복원

    dotnet tool restore

  2. 프로젝트에 .cursor/mcp.json 추가

    {
  "mcpServers": {
    "netwiv": {
      "command": "dotnet",
      "args": ["tool", "run", "netwiv", "--", "mcp"]
    }
  }
}

프로젝트의 .mcp.json과 같은 등록 정보입니다.

  1. 프로젝트 CLI 복원

    dotnet tool restore

  2. stdio 서버 등록

    command:   dotnet
args:      tool run netwiv -- mcp
transport: stdio

프로젝트 폴더에서 시작하세요. 프로젝트를 만들기 전에는 전역 설치한 CLI의 netwiv mcp가 가이드를 제공합니다.

코딩 에이전트 가이드 읽기스킬 저장소 보기

초기 개발 단계입니다. 아직 NuGet.org에는 없습니다. 지원 약속 없이 있는 그대로 제공됩니다.

왜 NetWiv인가

  1. 백엔드는 그대로 .NET입니다.

    NuGet 패키지, 의존성 주입, 설정, 로깅을 ASP.NET Core 앱과 같은 방식으로 씁니다.

    var builder = NetWivApplication.CreateBuilder(args);builder.Services.AddSingleton<GreetingCounter>();builder.Services.Configure<GreetingOptions>(...);

  2. 타입이 C#을 따라갑니다.

    빌드할 때 레코드가 TypeScript 인터페이스가 되고, Blazor 프론트엔드에는 타입이 있는 C# 클라이언트가 생성되어, 이름이 바뀐 필드를 컴파일러가 잡아냅니다.

    public sealed record Greeting(    string Message,    int Count);
    export interface GreetingOutput {  "message": string;  "count": number;

  3. 브라우저 엔진을 넣지 않습니다.

    페이지는 운영체제의 WebView가 그립니다. 패키지에는 Chromium 대신 앱만 들어갑니다.

    패키지에 포함앱 코드.NET 런타임 또는 NativeAOT네이티브 어댑터
    운영체제 제공WebView

  4. 배포 방식을 고릅니다.

    NativeAOT는 앱을 파일 몇 개짜리 네이티브 실행 파일로 컴파일합니다. 기본은 self-contained .NET이고, 설치된 런타임도 고를 수 있습니다. 플래그 하나로 바꿉니다.
