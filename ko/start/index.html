빠른 시작

CLI를 설치하고, 앱을 만들고, 실행하고, 게시합니다. 이어서 서로 통신하는 가장 작은 C#과 프론트엔드 코드를 봅니다.

NetWiv는 아직 NuGet.org에 없습니다. GitHub 릴리스 페이지의 ZIP에 패키지가 들어 있고, 압축을 푼 폴더를 패키지 소스로 씁니다.

필요한 것

  • .NET 8 이상 SDK
  • Node.js ^20.19 또는 22.12 이상
  • 운영체제 WebView: WebView2, WebKitGTK 4.1, WKWebView
  1. 1

    패키지 받기

    릴리스 페이지에서 ZIP을 받아 압축을 풉니다. 아래 명령은 다운로드 폴더에 풀었다고 가정하니, 다른 곳이면 경로만 바꾸세요. 새 프로젝트가 이 폴더를 가리키므로 지우지 마세요.

    NetWiv-0.2.2-packages.zip 받기

    릴리스에는 ZIP을 검증할 SHA256SUMS도 있습니다.

  2. 2

    CLI 설치

    압축을 푼 폴더에서 실행합니다. $feed에 패키지 위치가 저장됩니다. 이미 설치했다면 install 대신 update를 씁니다.

    Set-Location $HOME\Downloads\NetWiv-0.2.2-packages
$feed = (Resolve-Path .\packages).Path
dotnet tool install --global NetWiv.Cli --version 0.2.2 --add-source $feed
    cd ~/Downloads/NetWiv-0.2.2-packages
feed="$(pwd)/packages"
dotnet tool install --global NetWiv.Cli --version 0.2.2 --add-source "$feed"
export PATH="$HOME/.dotnet/tools:$PATH"
  3. 3

    앱 만들기

    $feed가 남아 있도록 같은 터미널에서 실행합니다. 기본은 React이고, netwiv new --list로 18개 템플릿을 볼 수 있습니다.

    Set-Location $HOME    # 프로젝트를 둘 폴더면 어디든
netwiv new MyNetWivApp --template react --source $feed
Set-Location MyNetWivApp
    cd ~    # 프로젝트를 둘 폴더면 어디든
netwiv new MyNetWivApp --template react --source "$feed"
cd MyNetWivApp
  4. 4

    실행

    바인딩을 만들고 Vite를 띄운 뒤 창을 엽니다. C#을 고치면 백엔드가 다시 시작됩니다.

    npm ci
npm run desktop:dev
    npm ci
npm run desktop:dev
  5. 5

    게시

    기본은 self-contained .NET이고, --aot를 붙이면 NativeAOT입니다. 결과는 target/에 생깁니다.

    dotnet tool run netwiv -- build
dotnet tool run netwiv -- build --aot
    dotnet tool run netwiv -- build
dotnet tool run netwiv -- build --aot

가장 작은 앱

React 템플릿에서 줄였습니다. 실제 템플릿은 개발 서버 연결도 함께 합니다.

강조된 줄에 마우스를 올리면 짝이 되는 줄이 함께 표시됩니다.

CLI 한눈에

명령하는 일
netwiv new NAME -t TEMPLATESDK 참조, 로컬 CLI, 피드를 갖춘 프로젝트 생성
netwiv new --list프론트엔드 템플릿 18개 보기
netwiv dev바인딩, 개발 서버, 백엔드 재시작과 함께 실행
netwiv buildself-contained .NET으로 게시. 설정에서 켜면 번들도 생성
netwiv build --aotNativeAOT로 게시
netwiv build --framework-dependent설치된 .NET 런타임용으로 게시
netwiv build -t osx-arm64 -b app,dmg대상과 번들 형식 지정
