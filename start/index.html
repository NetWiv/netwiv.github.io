Quickstart

Install the CLI, create an app, run it, publish it. Then the smallest C# and frontend code that talk to each other.

NetWiv is not on NuGet.org yet. Its packages come in a ZIP on the GitHub release page, and that folder acts as your package source.

You need

  • .NET 8 or later SDK
  • Node.js ^20.19 or 22.12+
  • The OS WebView: WebView2, WebKitGTK 4.1 or WKWebView
  1. 1

    Download the packages

    Get the ZIP from the release page and unzip it. The commands below assume it went to your Downloads folder; change the path if not. Keep the folder: new projects point to it.

    Download NetWiv-0.2.2-packages.zip

    The release also has SHA256SUMS to verify the ZIP.

  2. 2

    Install the CLI

    Run this in the unzipped folder. $feed remembers where the packages are. If the CLI is already installed, use update instead of install.

    Set-Location $HOME\Downloads\NetWiv-0.2.2-packages
$feed = (Resolve-Path .\packages).Path
dotnet tool install --global NetWiv.Cli --version 0.2.2 --add-source $feed
    cd ~/Downloads/NetWiv-0.2.2-packages
feed="$(pwd)/packages"
dotnet tool install --global NetWiv.Cli --version 0.2.2 --add-source "$feed"
export PATH="$HOME/.dotnet/tools:$PATH"
  3. 3

    Create an app

    Use the same terminal so $feed is still set. React is the default; netwiv new --list shows all 18 templates.

    Set-Location $HOME    # or wherever you keep projects
netwiv new MyNetWivApp --template react --source $feed
Set-Location MyNetWivApp
    cd ~    # or wherever you keep projects
netwiv new MyNetWivApp --template react --source "$feed"
cd MyNetWivApp
  4. 4

    Run it

    Generates bindings, starts Vite and opens the window. C# edits restart the backend.

    npm ci
npm run desktop:dev
    npm ci
npm run desktop:dev
  5. 5

    Publish

    Self-contained .NET by default; add --aot for NativeAOT. Output goes to target/.

    dotnet tool run netwiv -- build
dotnet tool run netwiv -- build --aot
    dotnet tool run netwiv -- build
dotnet tool run netwiv -- build --aot

CLI at a glance

CommandWhat it does
netwiv new NAME -t TEMPLATECreate a project with SDK references, local CLI and feed
netwiv new --listList the 18 frontend templates
netwiv devRun with bindings, dev server and backend restarts
netwiv buildPublish with self-contained .NET; bundles when the config enables them
netwiv build --aotPublish with NativeAOT
netwiv build --framework-dependentPublish for an installed .NET runtime
netwiv build -t osx-arm64 -b app,dmgChoose the target and bundle formats
netwiv infoShow the CLI and .NET SDK versions, OS and config
